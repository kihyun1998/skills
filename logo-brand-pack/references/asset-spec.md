# Brand Asset Specification

## Standard icon sizes

Create square icons at 1024, 512, 256, 128, 64, 48, 32, and 16 pixels.

## GitHub social preview

Use 1280 × 640 pixels.

## README banner

Use 1600 × 400 pixels by default. A different width is acceptable when needed, but retain a wide, minimal composition.

## Backgrounds

- Light: `#FFFFFF`
- Dark: `#0D0D0D` or an equivalent near-black
- Transparent assets: RGBA with true alpha transparency

## Optical padding

Square icons normally need approximately 15–20% visual breathing room around the master symbol. Use optical judgement rather than mathematical centering; never distort the mark to fill the available space.

## Source priority

1. Original SVG or other vector source
2. High-resolution transparent PNG
3. High-resolution raster artwork
4. Generative reconstruction, only when explicitly requested

Do not trace or regenerate an existing vector logo unnecessarily.
