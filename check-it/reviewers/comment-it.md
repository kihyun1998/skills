# What `comment-it` is given (9)

Read when `check-it` runs `comment-it`. `comment-it`'s SKILL.md body, below its
frontmatter, comes before this file in the prompt; this is that skill's
argument.

**Do not call `Skill`.** The method is the body above, in this prompt. Its
links resolve from `{{skill_dir}}`, the skill's folder: read them from there.

The argument: the repository's root, `{{repo}}`, and as the scope the change
*How you work* names, so only new and changed comments and suppressions are
read.
